
# Online Store

Проект интернет-магазина на Django. 
На текущем этапе реализован базовый каркас веб-приложения: настроена маршрутизация, подключены шаблоны с Bootstrap и запущен локальный сервер разработки.

## Стек технологий
- **Python** 3.x
- **Django** 
- **Poetry** (управление зависимостями)
- **Bootstrap 5** (стилизация страниц)

## Доступные страницы
- `catalog/` — Главная страница (`home`). Базовая витрина магазина.
- `catalog/contacts` — Контакты (`contacts`). Контактная информация и форма обратной связи.

## Установка и запуск

1. **Клонируйте репозиторий:**
 git clone https://github.com/RomanShumakov/online-store.git
 cd online-store

2. **Установите зависимости:**
 poetry install

3. **Активируйте виртуальное окружение:**
 poetry shell

4. **Примените базовые миграции:**
 python manage.py migrate

5. **Запустите локальный сервер:**
 python manage.py runserver

После запуска проект будет доступен по адресу: 
`http://127.0.0.1:8000/`

## Структура проекта
- `manage.py` — утилита управления проектом Django.
- `templates/` — HTML-шаблоны страниц с использованием тегов шаблонизатора Django.
- `static/` — статические файлы (CSS, js, кастомные стили, изображения).
