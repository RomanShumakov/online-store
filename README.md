# Online Store

Проект интернет-магазина на Django. 
На текущем этапе реализован базовый каркас веб-приложения: настроена маршрутизация, подключены шаблоны с Bootstrap, спроектированы модели данных с базой PostgreSQL, настроена административная панель и подготовлены кастомные команды для наполнения базы.

## Стек технологий
- **Python** 3.x
- **Django**
- **PostgreSQL** (реляционная база данных)
- **Poetry** (управление зависимостями)
- **Bootstrap 5** (стилизация страниц)

## Доступные страницы и интерфейсы
- `catalog/` — Главная страница (`home`). Базовая витрина магазина.
- `catalog/contacts/` — Контакты (`contacts`). Контактная информация и форма обратной связи.
- `admin/` — Панель администратора Django с настроенными фильтрами и поиском по товарам и категориям.

## Установка и запуск

1. **Клонируйте репозиторий:**
 ```bash
 git clone https://github.com/RomanShumakov/online-store.git
 cd online-store
 ```

2. **Установите зависимости:**
 ```bash
 poetry install
 ```

3. **Активируйте виртуальное окружение:**
 ```bash
 poetry shell
 ```

4. **Настройте переменные окружения:**
 Создайте файл `.env` в корне проекта и укажите параметры подключения к базе данных и настройки приложения:
 ```env
 SECRET_KEY=ваш_секретный_ключ
 DEBUG=True
 DB_NAME=имя_базы_данных
 DB_USER=пользователь_бд
 DB_PASSWORD=пароль_бд
 DB_HOST=localhost
 DB_PORT=5432
 ```

5. **Примените миграции:**
 ```bash
 python manage.py migrate
 ```

6. **Наполните базу данных тестовыми данными:**
 - Быстрая загрузка данных из фикстур:
 ```bash
 python manage.py load_fixtures
 ```
 - Либо создание товаров через ORM:
 ```bash
 python manage.py add_products
 ```

7. **Создайте суперпользователя (для доступа к админке):**
 ```bash
 python manage.py createsuperuser
 ```

8. **Запустите локальный сервер:**
 ```bash
 python manage.py runserver
 ```

После запуска проект будет доступен по адресу: `http://127.0.0.1:8000/`

## Структура проекта
- `manage.py` — утилита управления проектом Django.
- `catalog/` — основное приложение каталога (модели, представления, URL, админка).
- `catalog/fixtures/` — фикстуры в формате JSON для быстрого развёртывания тестовых данных.
- `catalog/management/commands/` — кастомные консольные команды управления данными.
- `templates/` — HTML-шаблоны страниц с использованием тегов шаблонизатора Django.
- `static/` — статические файлы (CSS, JS, кастомные стили, изображения).
